🦃 HandsFree Pet — one-time setup

Chrome needs you to allow the camera once for this extension. Click the button, then choose Allow.

Then click the 🦃 toolbar icon (puzzle-piece menu → pin it) to switch the pet on. The pet's voice typing asks for the microphone once per website, the first time you use it there.

If the pet says "assets missing", run get-assets.sh (Mac/Linux) or get-assets.ps1 (Windows) in the extension folder, then reload the extension.
